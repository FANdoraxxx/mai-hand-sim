## 2. 真人手元标注可靠性、指尖/透视/视差校正、双平凡基线对比与 50 个可核对案例（对应返修项 2）

### 2.1 原先手元标注与规划器基准失真的三项根因
1. **掌心 vs 指尖解剖学偏移（`86.8 mm`）**：
   - 原 `handcam_collector.py` 使用掌心（`0.45 * wrist[0] + 0.55 * middle_mcp[9]`）计算与按键靶心的距离。统计 `kp/*.npz` 中全部 **30,462 帧** MediaPipe 21 关键点真实检出帧可见，从掌心到击打指尖（`0.5 * (index_tip[8] + middle_tip[12])`）的中位解剖学长度为 **`86.8 mm`**（75 分位 **`106.1 mm`**）。当玩家用指尖触碰 `R = 215 mm`（内屏 A 区）或 `R = 310 mm`（外键）时，掌心天然位于向肩部锚点 $(\mp 190, -340)\text{ mm}$ 缩进约 `87 mm` 处，导致即便指尖正中靶心，掌心距离误差也高达 `~87 mm`，使得 `< 40 mm` 比例中位数仅有 `18%`。
2. **非采样帧（`fi % 5 != 0`）的半屏亮斑均值污染**：
   - 原采集器仅在 `fi % 5 == 0` 帧调用 MediaPipe，其余 80% 帧使用屏幕帧差亮斑按中位数 `mid_x` 左右二分的均值（`l_m = xs_full <= mid_x, r_m = xs_full > mid_x`）作为兜底。这导致 80% 帧的左/右手坐标被强行拉向左右半屏飞行音符亮斑的几何中心 `(±85, 0) mm`，使旧 `human_note_hands` 退化为近似的“左半屏归 L、右半屏归 R”标签器（甚至将 `PANDORA PARADOXXX` 中 150 BPM 16 分音符 `7-8-7-8-7-5-7-8-7` 标成单手 `L` 连打 9 押）。
3. **规划器 `planner.py` 在单手相位与非滑条双押上的偏差**：
   - 原 `planner.py` 在滑条 `judge_time` 到期时，即便该手早已提前驻留（early-park）并离开去拍击后续单点，仍把 `cur_left_xy / cur_right_xy` 强行重置回旧滑条终点，引发后续单点串左右手反相锁死（如 `L` 打右侧 `3`、`R` 打右侧 `4`）；同时普通双押 Tap 在 `dt <= 0.095s` 时允许低代价交叉，且单侧长交互（`same_hemi_fast_len >= 3`）首押未按“左手在左、右手在右（$x_L \le x_R$）”选择起手。

## 5. 有趣度默认权重来源与可玩性门控结论说明（对应返修项 5）

1. **`DEFAULT_INTEREST_WEIGHTS` 的来源说明**：
   - `sim_core/vocab_and_rarity.py` 中的 `DEFAULT_INTEREST_WEIGHTS`（`vocab_entropy = 0.22`, `phrase_development = 0.16`, `motif_echo_transformed = 0.18`, `chorus_peak_contrast = 0.18`, `music_kinetic_coupling = 0.14`, `anti_stagnation = 0.12`）是**人工设定的启发式先验默认权重**，用于在尚未提供人类成对偏好标注文件（`scratch/simv3/prefs/*.jsonl`）时给出合理的初始线性组合。当 `scratch/simv3/prefs/*.jsonl` 存在标注数据时，`load_interest_weights()` 会自动通过正则化 Bradley-Terry 逻辑回归拟合并替换该默认权重。
2. **可玩性门控（Playability Gate）对坏谱得分的作用说明**：
   - 在未乘可玩性门控前（`raw_interest_score`），坏谱集 `neg_csft_s3000` 因为包含大量高频乱跳与高密度动作变化，其原始动作丰富度得分为 **`71.19`**（高于 `champ_slide80` 的 **`69.32`**，接近留出官谱的 **`74.26`**）。
   - `neg_csft_s3000` 的最终 `interest_score` 降至 **`46.25`**（低于 `champ_slide80` 的 **`68.42`** 与留出官谱的 **`74.06`**），**完全是因为我们在架构设计上显式乘上了可玩性门控系数** `playability_gate = max(0.05, 0.85^n_hard * (1 - 0.35 * awkward_mean))`（对不可玩谱面直接按硬性违规数折减），**这是门控规则的设计使然，而不是 6 项原始有趣度特征自己学到了区分坏谱与好谱**。
   - 在可玩谱面内部（排除硬性违规后），6 项原始有趣度特征衡量的是“动作词汇多样性、段落递进、跨段动作呼应与音画耦合”，生成谱在这些维度上普遍低于留出官谱（`raw_interest_score`: 官谱 `74.26` vs 生成谱 `68.25 ~ 70.11`，Cohen's $d = +0.86 \sim +1.18$）。
